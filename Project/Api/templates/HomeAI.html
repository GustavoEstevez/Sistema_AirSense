¿Por qué AirSense?

No podemos mejorar
lo que no medimos

Estudiantes y docentes pasan gran parte del día en aulas donde la temperatura, la humedad y el ruido afectan el bienestar y el rendimiento académico. Sin embargo, estas condiciones rara vez son monitoreadas.

Tecnología

Cómo funciona

AirSense monitorea continuamente las condiciones ambientales y transforma los datos en información útil.

01

Arduino mide

El DHT11 mide temperatura y humedad. El KY-038 captura el nivel de ruido ambiental en decibeles cada 2 segundos.

→
02

Los datos viajan

Los datos se transmiten por comunicación serial USB a la computadora en formato JSON, en tiempo real y sin interrupciones.

→
03

Dashboard analiza

El sistema visualiza métricas, detecta valores fuera de rango y genera alertas automáticas con recomendaciones según estándares OMS.

Componentes del sistema

AirSense

Dispositivo Completo

Sistema de monitoreo ambiental desarrollado para medir temperatura, humedad y ruido en tiempo real. Integra sensores, visualización local y dashboard web para generar métricas y recomendaciones.

Arduino UNO

Microcontrolador

Cerebro del sistema. Procesa las lecturas de los sensores y gestiona la comunicación serial y las alertas visuales.

DHT11

Temperatura y Humedad

Precisión ±0.5°C y ±2%. Mide las condiciones térmicas del ambiente cada 2 segundos en tiempo real.

KY-038

Sensor de Sonido

Micrófono analógico. Captura el nivel de ruido ambiental estimado en dB mediante calibración matemática.

LCD 16x2

Display Local

Con módulo I2C. Muestra temperatura, humedad y ruido directamente en el dispositivo sin necesidad de computadora.

LED RGB

Indicador Visual

Verde = saludable, amarillo = advertencia, rojo = alerta. Retroalimentación inmediata del estado ambiental.

Sobre el proyecto

Ingeniería y Tecnología
en acción

AirSense es un proyecto de la categoría Ingeniería y Tecnología — Categoría B (trabajos institucionales) presentado en la Feria de Educación, Arte, Ciencias y Tecnología (ACTE) 2026 de la Provincia de Buenos Aires.

El proyecto surge de una pregunta investigable: ¿las condiciones ambientales de los espacios de nuestra escuela son saludables? Para responderla, el equipo desarrolló un sistema de monitoreo completo que combina hardware Arduino con una plataforma web de visualización en tiempo real.

La Carpeta de Campo registra todo el proceso de investigación, desde las hipótesis iniciales hasta los resultados obtenidos, siguiendo los lineamientos curriculares de la DGCyE Buenos Aires.
